## Ask

Temp files from tests, gates, traces and finished writers must not pile up on this host. Every leak is fixed where it happens, with a test that fails before the fix. Each lease gets its own temp directory, and that directory dies with the lease. Each run's temp dies with the run, including a killed run. Finished leases are swept from hooks alone. SubagentStop marks a lease finished. Every Stop sweeps what has been finished and quiet for 30 minutes: it kills leftover processes in the lease, deletes its temp, deletes the tree when gc's rules allow, and prints what it removed. This must stay fast with 5-15 worktrees.

## Decisions

- D1 **Per-lease TMPDIR, delivered by BASH_ENV.** WorktreeCreate (`make_lease`) creates `/var/tmp/r<uid>/<first 8 hex of the agent id>` with mode 0700 and records it as `tmpdir`. `bash_env.sh` exports it when `$PWD` is inside `*/.claude/worktrees/<id>` and TMPDIR is unset or still equals `$CLAUDE_CODE_TMPDIR`, meaning nobody has narrowed it since the harness. A TMPDIR set by pytest, vitest or a gate is left alone. Why /var/tmp: it is on disk (ext4, 589 GB free) and the path is 23 bytes. That keeps it within runtmp's `DEEP_TMPDIR` socket budget, so nested run dirs stay on disk instead of falling back to /tmp. It is also a system temp base, so seams accept it (D3). Ad-hoc `mktemp` in an agent's shell follows the variable. Git hooks inherit it, which makes `gen-docs-precommit-<key>` per-lease. The alternative, rewriting every Bash command through PreToolUse `updatedInput`, was rejected: it changes the text that later guards and the transcript see. Operator veto in Open questions 1.
- D2 **Per-run temp means a pid-stamped run dir.** Every tool that makes temp makes one run dir, `<prefix><pid>-n<pidns>-<rand>`, through `runtmp.run_dir` (Python) or a new `scripts/lib/runtmp.ts` using the same stamp. The dir is removed at exit and on SIGINT, SIGTERM and SIGHUP. A SIGKILLed run's dir is removed by the next run's `sweepDead` and by HT12. The two languages share one stamp, so either sweeper removes the other's dead dirs.
- D3 **pytest scratch moves to disk and is removed.** `seams.system_temp_base` returns /var/tmp when /tmp is a tmpfs, read from /proc/mounts as `vm_check.tmp_is_tmpfs` already does, so seam rule (a) stays env-free. `scratch_tmp` uses `runtmp.run_dir("rediacc-pytest-", base)` and removes it in `config.add_cleanup`. Inside a lease, the lease TMPDIR already sits under that base, so `install` leaves it in place and the run's temp goes with the lease.
- D4 **strace log limit.** `traceCommand` takes `maxLogMb` (default 8192, flag `--max-log-mb` on both tools). A watchdog every 5 s sums the sizes of the `t.*` files. Over the limit, it SIGKILLs the group and returns exit 125 with `capped: true`. trace-honest reports this as finding `trace-log-cap` (gate id, bytes, "split the gate or raise --max-log-mb"), never as a PASS. Before each trace, trace-honest waits until free space on the log filesystem is at least `jobs × maxLogMb + 20 GB`, and refuses after 10 minutes. `-s 4096` and the syscall set stay as they are, because shortening paths would mis-attribute reads.
- D5 **No detached spawn escapes a kill.** Every `detached: true` spawn under `scripts/ci-runner` goes in `LIVE_GROUPS` (or that tool's own equivalent) and carries the runner-death watch of `exec.ts:62` (fd 4 EOF → `kill -KILL 0` of its own group). trace-honest gets the same signal handler as path-trace, and both handlers remove their run dirs before exiting.
- D6 **"Finished" means all of the following:**
    - a SubagentStop marker `<common>/rediacc-worktrees/<lease id>.finished` with `{"agent", "finished_at", "transcript"}`, written only on a non-interim stop and rewritten on every later final stop;
    - `finished_at` is at least 1800 s ago;
    - the transcript mtime is at least 1800 s ago;
    - the harness meta shows `finished: true` when the meta exists. A resume clears it, so a woken agent is never swept;
    - no `[>]` worklist item names the lease;
    - no live roster row holds the lease.

  A lease with no agent (a hand-run `./run.sh worktree lease`) never gets a marker and stays under gc's existing rules only.
- D7 **The sweep runs detached and the next stop prints it.** Each Stop does a cheap check inline: list the records directory, then stat the markers, transcripts and the results file. No git, no `du`. It starts at most one detached sweeper per git common dir (O_EXCL lock with dead-pid takeover, at most one start per 5 minutes, `nice 19`, `ionice -c3`), following the `wl_opshealth` pattern. Removing a 6 GB tree, and checking gc rules 3 and 4 with git status on each repo, takes seconds to minutes. Inline, that would make the 5-15 sessions wait on each other's stops. The sweeper appends rows to `<common>/rediacc-worktrees/sweeps.jsonl`. Each session's stop prints the rows after its last printed sequence number, one time, as a sticky `outq_add` section `host-temp`. Inline budget: 150 ms at p95 with 15 leases. Operator veto in Open questions 2.
- D8 **What the sweep does to a finished lease, in this order.**
    1. Re-judge D6 immediately before acting.
    2. Kill this uid's processes whose cwd is under the lease tree or its tmpdir, or whose `/proc/<pid>/environ` TMPDIR is under its tmpdir. Never the sweeper's ancestors and never a `claude` process. Before each kill, re-read the cwd and compare the start time (`/proc/<pid>/stat` field 22). SIGTERM, then SIGKILL after 5 s, up to 3 rounds to catch new forks.
    3. Delete the lease tmpdir, its typecheck cache dir and its `gen-docs-precommit-<key>` if that sits outside the tmpdir. These are temp, never work.
    4. Call `run_gc(write=True, only=<id>)`. The tree goes only when rules 1-4 and the hold rule all pass. A KEEP is printed with its rule, and the temp is gone either way.

  This replaces `wl_bgsweep`'s notify-only rule for finished leases, under the operator ruling of 2026-11-26. The bgsweep docstring gets one line saying so.
- D9 **gc removes a lease's satellites.** `_remove_row` deletes the lease tmpdir, `cacheDirFor(path)` and `gen-docs-precommit-<sha1(git_dir)[:12]>` together with the tree. Manual `gc --write` and the WorktreeRemove hook clean up the same way the sweep does.
- D10 **Host-level dead-run sweep.** Each sweeper run also calls `sweep_dead` for every registered prefix in `$CLAUDE_CODE_TMPDIR`, /var/tmp/r<uid> and /tmp. The prefixes are listed in `host_temp.PREFIXES`, and a test checks the list against every `runDir` / `run_dir` prefix found in the tree. It also removes typecheck cache dirs whose checkout path is gone, but only for names starting with `home-<user>-console-.claude-worktrees-`.

## Design

1. **HT0 probe.** `python3 -m rediacc_ci.dev.temp_probe -- <cmd>` runs `<cmd>` with TMPDIR set to a fresh 0700 dir. It snapshots this uid's top-level entries in /tmp, /var/tmp/r<uid> and `$CLAUDE_CODE_TMPDIR` before and after. It exits 1 and lists every survivor in the fresh dir, plus every new entry outside it, labelled "ignored TMPDIR". `census` groups today's entries by prefix with count, size and inodes, and maps each prefix to its source with `git grep`. Every source-fix box proves its fix with this probe: rc 1 on the parent commit is quoted in the tick evidence, and rc 0 after the fix.
2. **`scripts/lib/runtmp.ts`.** `runDir(prefix, base?)`, `shared(prefix)`, `sweepDead(prefix, base)` and `removeTree`. Exit cleanup uses `process.on('exit')` plus a signal hook that callers chain, so it never replaces their own handler. Same stamp, prefix rule and `DEEP_TMPDIR` as the Python module.
3. **path-trace and trace-honest.** Every `mkdtempSync(os.tmpdir(), ...)` becomes `mkdtempSync(path.join(shared('path-trace-'), ...))`, or `trace-honest-` for that tool. `traceCommand` wraps its parse in try/finally. Both entry points install one handler that kills groups, removes run dirs and exits 130. `runPlain` registers its group. The strace watchdog follows D4.
4. **vitest.** `scripts/lib/vitest-run-tmp.ts` is a `globalSetup` that makes `runDir('rediacc-vitest-')`, sets `process.env.TMPDIR` before workers fork, and removes the dir in teardown. Every `vitest.config.ts` lists it. `isolate-config-home.ts` creates its home under that dir.
5. **SubagentStop marker.** `wl_worktrees.mark_finished(root, agent_id, transcript, interim)` writes or rewrites the marker atomically when `agent-<agent_id>` has a record and the stop is not interim. It is swallowed like every other follow-up in `handle_subagent_stop`, which keeps the "never wedge a sub-agent's stop" contract (`wl_report.py:1034`).
6. **Stop segment `host-temp`** (tier `advisory`, placed after ops-health in `run_stop`). `wl_hosttemp.assess(root, session_id, state_doc)` returns `{"due": bool, "print": [lines]}`. When the sweep is due, it starts `python3 -m rediacc_ci.dev.host_temp sweep --lock-held` through the lock. Printed form:
   `host-temp: removed tree agent-a41410706709 (2.1 GB) and its temp (6.0 GB); killed 4 processes in agent-ab385dcf59f1 (node x3, strace x1); kept tree agent-a4e219b0318b (rule 4: 1 unlanded commit), temp removed (0.4 GB); swept 12 dead run dirs (31 GB)`.
7. **`host_temp.py` verbs.** `sweep [--lock-held]` (D8, D10). `reclaim --legacy [--write]` for the unstamped leftovers made before this plan: listing by default, delete only with `--write`. `status` (what the next sweep would do, read-only). Under `--legacy`, an entry is removed only when:
    - no process has an open fd or cwd under it (one `/proc/*/{cwd,fd}` scan per run);
    - its top-level mtime is at least 30 minutes old;
    - for `path-trace-*`, no running strace has an `-o` argument under it.
