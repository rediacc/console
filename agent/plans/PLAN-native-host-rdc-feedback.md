## Why

The restore onto native Ubuntu (2026-11-25) hit these, in the operator's order of importance:

1. `./rdc.sh --config eu-remote subscription status` failed with "Enroll this device again with: rdc config remote enable". Run as printed it enrolls the default config, which happened and cost a second browser 2FA round. The command text is a literal in the locale strings (`packages/cli/src/i18n/locales/en/cli.json:334`, `:427`, `:428`); `RemotePasskeySecretMissingError` takes no arguments although the adapter holds `configName` (`packages/cli/src/adapters/remote-config-adapter.ts:119`). Siblings: `packages/cli/src/commands/config-remote-relay.ts:209,242,260`, `packages/cli/src/adapters/remote-token-storage.ts:247`, `packages/cli/src/services/account/subscription-device-auth.ts:141,168`.
2. "The kernel keyring is emptied at every restart" was shown on a device that never held the key (configs copied from another machine). Nothing records a past enrollment, so the CLI cannot tell the two apart.
3. On Linux the device key lives only in the kernel keyring (`packages/cli/src/utils/secure-storage.ts:136-170`), so every reboot costs one browser 2FA per config. macOS (Keychain) and Windows (DPAPI) already persist across reboots; the gap is Linux-only. Operator ruling 2026-11-25: add a Secret Service (libsecret) backend and keep the kernel keyring as the fallback where no session bus exists.
4. `config remote enable` overwrote an older `rediacc.json.bak`; the generic `createBackup` (`packages/cli/src/adapters/config-file-storage.ts:178-190`) is last-save-wins by design, so the enable path needs its own unique pre-enable copy.
5. The first rdc command after setup failed with "keyctl is not installed": `.ci/rediacc_ci/setup/tools.py` has no keyctl row and `rdc doctor` has no secret-store check.
6. `./rdc.sh --native` on a fresh machine: it does not resolve `ACCOUNT_ED25519_PUBLIC_KEY` (`.ci/rediacc_ci/native.py:163-170` calls `build.sh stage_linux` without the key `resolve_renet_account_key` supplies on the regular path), refuses when `~/.local/share/rediacc/bin` is absent (`.ci/rediacc_ci/native.py:191-193`), and prints a backup path it never wrote (`.ci/rediacc_ci/native.py:198`).
7. The old-envelope warning names a config by GUID and prints twice per run (`packages/cli/src/adapters/remote-config-adapter.ts:155-157`; siblings `envelopeTooNew`, `envelopeDowngrade`).

Found by the host bring-up of the same day: Ubuntu 26.04 has no `sg`, so the docker-group re-exec (`.ci/rediacc_ci/core/dockerx.py`, `.ci/rediacc_ci/core/local_common.py:1282-1296`, `.ci/rediacc_ci/setup/machine.py:105-126`, and the shell copy, deleted in 111d5c3810 when it was ported to Python) cannot work there; and `/tmp` is a quota'd tmpfs that broke vm:check's A1.1 suite with EDQUOT.
