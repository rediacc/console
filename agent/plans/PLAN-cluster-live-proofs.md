## Design

**D1. The lab never touches the shared fleet.** Every live box here builds its own KVM clusters with `rdc cluster create --provider kvm` on `renet13`/`192.168.113` (a net no other cluster uses), and tears them down with `rdc cluster destroy`. VMs 11, 12 and 21-23 are never used. The topology is PLAN-multicluster-local-suite.md's site A (`lab-a`: one control VM, two Ceph VMs at `VM_RAM_CEPH=2560`, one k8s-server and one k8s-agent at `VM_RAM_WORKER=3072`, about 12 GiB), plus a k8s-only dest cluster `lab-d` on the same net at `--net-offset 40` (one control VM and one k8s-server, about 4 GiB) so the fork dest reaches the source Ceph monitors.

**D2. Linode demo: there and back, then destroy.** A new `crossdc` phase in the harness migrates the lab cluster to a Linode site and back, so the lab cluster survives and the Linode site can be destroyed with nothing stranded. The Linode site is `CLUSTER_POOLS=ceph:ceph:3:g6-standard-2#/dev/sdc@40,k8s:k8s-server:1:g6-standard-2` on a provider entry whose region is `de-fra-2`. A marker row written to a Postgres fixture on the lab cluster before the first cutover must read back after each cutover. Both `Cutover downtime` lines are recorded. The transfer path is the host-relayed stream PLAN-cluster-crosssite-transport.md designs (its D1), which is what makes a NAT-ed lab VM and a public Linode node reachable from one place.

**D3. Cost is printed and capped before anything billable.** `preflight` gains a cost estimate read from the Linode API (`GET /linode/types/<type>` `price.hourly` per instance, plus `GET /volumes` pricing at $0.10/GB-month, verified at run time) multiplied by a declared window (`CROSSDC_HOURS`, default 3), and refuses a run whose estimate exceeds `COST_CAP_USD` (default 1.00). Expected figure today: 4 x g6-standard-2 at about $0.036/h plus 120 GB of volumes at about $0.016/h, about $0.16/h, so about $0.50 for 3 hours. `preflight` also refuses a region whose `capabilities` lack `Vlans`.

**D4. Rehearse and replicate remove are proven by ground truth, not exit codes.** The rehearse run records each leg from renet state on the dest (`renet datastore list --json`, the fork CA fingerprint against the parent's, `kubectl get --raw /readyz` through the fork kubeconfig before discard), and after the discard asserts no `:<tag>` record and no mapped rbd device remains. Suite 24 test 7 gains the survivor check #95 needed: after `replicate remove`, no StatefulSet, Service or fork datastore of the set survives.

**D5. Spegel is switched on per cluster at create time.** `rdc cluster create --embedded-registry` passes `embedded_registry: true` to the server's `kube_install`, through a new FunctionDef param that emits `--embedded-registry`. Agents need nothing (Context 8). Off by default, matching upstream k3s. If S0 shows Spegel needs a mirrors file the CLI path does not write, S2 also passes the `registries_yaml` that renet renders; a renet-side render inside `kube_install.go` would collide with PLAN-canary-on-clusters.md's C2 and is out of scope here.

Out of scope: same-machine concurrent forks (netns-per-cluster, dropped by the operator), the cross-site transport itself (PLAN-cluster-crosssite-transport.md), and the automated rehearse e2e (PLAN-multicluster-local-suite.md).

## Risks

- **Host memory.** `lab-a` plus `lab-d` is about 16 GiB against 27 GiB available beside the shared fleet; S3 adds about 10 GiB and runs only after B4. A box that finds less than its topology plus 4 GiB free waits rather than squeezing.
- **Linode spend and leftovers.** A4 is the only billable box. The cap refuses an over-estimate before `provision`, and `verify` runs after `destroy` in the same invocation (exit 4 on a survivor, resolved before ticking). A crash mid-`crossdc` leaves the cluster on one side: the marker check names which, and the harness prints the `rdc cluster migrate` command that brings it back before `destroy` runs.
- **Relay bandwidth.** The cross-site stream passes through the operator's host; a slow uplink stretches the pre-copy, not the downtime, because the final diff is small by design.
- **Spegel peer port.** The eBPF /26 ACLs may block Spegel's peer port between nodes; S0 records it, and a block becomes a finding fixed under this plan's S boxes rather than a skipped proof.
- **Cluster-ops clearance.** B, S and A boxes run cluster verbs; a session without `REDIACC_ALLOW_CLUSTER_OPS` in its launching shell cannot run them and must say so rather than route around the policy.
