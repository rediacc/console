## Rulings (operator /ask, 2026-10-30)

- R1. Licensing is enforced always and everywhere, GitHub runners included: "no license is not acceptable". REDIACC_SKIP_MACHINE_ACTIVATION is removed entirely, with no replacement switch.
- R2. CI builds renet ONCE per run and shares it as a small linux-amd64 artifact; test jobs `needs:` Build (Renet). The per-run CI account server gets the PRODUCTION private key from bws (chosen over a delegation cert), so the shared production-keyed renet accepts its licences. This supersedes PLAN-production-key-only D6 ("the production private key must never reach a public-PR job").
- R3. e2e repository creation through raw renet, tutorials and renet integration tests each obtain and install a licence per repository GUID.
- R4. A FREE licence ("Free License") is issued by every server (3 stable, 3 edge, bench, local accounts with real keys via bws): plan code FREE, no subscription row (`subscriptionId` `free:<hash>`), 3 GB repository cap, 48 h validity.
- R5. At FREE expiry ONLY new work stops (create, fork, resize, expand, backup push/pull); running and restarting repositories keep working, which is the current renet tier semantics.
- R6. FREE renewal is UNLIMITED: the renew route accepts FREE, each renewal extends 48 h, and renewals do not count against the per-IP limit.
- R7. Per-IP limit: 8 new FREE licences per 72 h, counted PER SERVER; key = IPv4 address or IPv6 /64, stored only as a keyed hash; rows purged after 72 h; a privacy-policy line (legitimate interest, abuse prevention).
- R8. Per-machine cap: at most 3 active FREE licences per machineId, and a repository GUID that already had a FREE licence is refused a new one.
- R9. Requesting machines are traced: hashed IP key (HMAC of the whole IPv4 address, or of the IPv6 /64; "prefix" in the column names `ip_prefix_hash` means that key), machineId, clientMachineId, repoGuid and time per issuance. A caller whose IP resolves to `unknown` (including service bindings) is refused, never counted.
- R10. The FREE counter is D1-backed and ignores TEST_MODE; a Cloudflare WAF rate rule guards the route as well.
- R11. CLI: when not logged in, offer "log in, or use a 48 h free licence (3 GB)"; agents and `--yes` take the FREE licence automatically, with a warning and the signup link.
- R12. COMMUNITY may license again: the 2026-07-07 trial-first gate is lifted.
- R13. FREE has no hosted backup plane and is not billed (issuance is event-logged and excluded from billing reports); the CLI and portal encourage upgrading to a paid plan when a FREE user tries backups.

## Design

1. **Wire.** `POST /licenses/free`, no auth. Body: machineId, clientMachineId, repositoryGuid, grandGuid?, datastoreId?, kind. Response: the same signed repo-licence shape as `/activate-repo`, `planCode: FREE`, `maxRepositorySizeGb: 3`, `hardExpiresAt` = now + 48 h, plus `signupUrl`.
2. **Identity.** `subscriptionId` = `free:` + hex of HMAC-SHA256(`FREE_LICENSE_HMAC_KEY`, machineId), first 16 bytes. Sequence and chain hash are kept per (free id, repositoryGuid) in the new table, so renet's per-repo chain scope holds.
3. **Schema (0071_free_license.sql).** `free_license_issuances` (id, free_subscription_id, ip_prefix_hash, machine_id, client_machine_id, repository_guid UNIQUE, sequence, chain_hash, issued_at, expires_at, revoked_at), and `free_license_ip_window` (ip_prefix_hash, issued_at), indexed on (ip_prefix_hash, issued_at). The IP key (the "prefix" of `ip_prefix_hash`) is HMAC-SHA256 of the whole IPv4 address, which is its /32, or of the IPv6 /64; the raw address is never stored.
4. **Issuance order.** Refuse `unknown` IP (R9) -> D1 count of the IP window in the last 72 h, refuse at 8 -> count unexpired rows for machineId, refuse at 3 -> refuse a repositoryGuid already present -> sign, insert both rows in one atomic batch, event-log `free_license.issued` with no billing tag. The reads before the sign give the precise refusal; the issuance insert is `INSERT ... SELECT ... WHERE` that re-asserts the IP-window bound, the per-machine cap and the unused repositoryGuid inside the same statement, and the window row is inserted only if that issuance row exists, so concurrent first-time requests from one IP key cannot all pass the check and the bound holds under a race. The check ignores TEST_MODE; tests seed the window directly.
5. **Renewal.** `renewRepoLicense` routes a `free:` blob to the FREE service: verify signature, machine and repo binding, the row exists and is not revoked, bump the sequence, re-sign with a fresh 48 h window. No IP window row is written (R6).
6. **Purge.** The scheduled handler deletes `free_license_ip_window` rows older than 72 h; issuance rows keep only the hashed prefix.
7. **Plan maps.** FREE joins PlanCode with limits {maxRepositorySizeGb 3, issuances 0, storageQuotaBytes 0}, max machines 0 (no activation row), no delegation certs, below COMMUNITY in PLAN_ORDER, every backup feature off. renet gains `PlanFree`; the generated contract is regenerated through check:ci-renet-types.
8. **CLI.** With no token: interactive prompt offers login or FREE; agents and `--yes` take FREE with a warning naming the 3 GB cap, the 48 h window and the signup link. Backup verbs on a FREE repo print the upgrade message instead of a raw refusal.
9. **CI.** Build (Renet) produces the one linux-amd64 binary; every test leg downloads it, verifies it with renet_key_gate, and starts its account server with the production pair from bws through the bws-secrets action.

## Risks

- **CGNAT and shared NAT.** Many users behind one IPv4 share 8 licences per 72 h per server. Renewal is unlimited and needs no window slot, so only first-time issuance is throttled; the refusal names the signup link.
- **Shared CI IPs.** Irrelevant: CI signs with the production key on its own per-run server (R2) and never calls a public server's FREE route.
- **Production key on runners.** Accepted by R2. Fork PRs receive no bws token, so the key reaches only jobs that already hold repository secrets.
- **D1 write cost.** Two rows per issuance and one update per renewal; the purge keeps the window table at most 72 h deep. The WAF rule stops floods before they reach D1.
- **Machine-id spoofing.** machineId is client-chosen; the per-IP window is the real bound, and the per-GUID refusal stops a renewal-free re-issue loop on one repository.

## Alternatives rejected

- **A delegation cert for CI.** The operator chose the production key over a per-run delegation cert (R2).
- **A synthetic subscription row per FREE machine.** It would satisfy the foreign keys but put unbilled rows into every subscription report and count query; a separate table keeps FREE out of them by construction.
- **The in-memory limiter.** Per isolate and bypassed in tests (private/account/src/middleware/rate-limit.ts:58-64), so it cannot carry R7.
