## Decision
- `docker_running` means "the repo's dockerd answers its Docker socket right now". It is probed on every read and never persisted.
- `daemon.Answers(networkID)` is the single probe, exposing the existing `socketRespondingProbe`. List gets the same answer from its GUID-matched socket map.
- List: `docker_available` is removed because it would duplicate `docker_running`. The container boolean becomes `containers_running`. It is kept rather than dropped because reconcile and the table both need "containers exist but all exited", which `container_count` alone cannot express.
- The persisted flag is deleted. Old .rediacc.json files that still carry `docker_running` decode fine, because no reader uses DisallowUnknownFields.
- This is a clean break with no shims.
