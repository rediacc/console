## Ask

The 2026-07-07 conversion audit found the marketing site saying things that are not true. A button reads "Start free trial" and opens a contact form. A button reads "Install Rediacc Free" and opens the account portal. A pricing button reads "Start free trial" and opens an install page with no signup. Twenty solution pages and three persona pages carried invented customer quotes; the render was switched off on 2026-07-19, but the invented text still ships in every locale file and the component waits to be switched back on. The checkout success page fires a `purchase` event that never runs, because Stripe never returns there.

This plan makes each label name its real destination, deletes the fabricated content outright (operator rule: no fabricated social proof), deletes the dead success page, and narrows analytics to the production host. A later phase adds an honest proof section built only from measured, linked numbers.

The portal half of #519 (portal analytics, `trial_start` and `purchase` on the real Stripe return page, the post-checkout `returnUrl`, the unused web register client) is PLAN-portal-analytics.md. No existing plan in agent/plans or agent/plans/_done covers either half (grep for socialProof, CATEGORY_CTA_MAP, plausible, trial_start and funnel on 2026-11-16).

## Design

- **Bottom CTA: trial first, contact second.** The bottom primary becomes the trial intent `/account/?checkout=PROFESSIONAL&period=monthly`, so "Start free trial" opens exactly what it says, through the same region-picker handoff as the pricing cards, and fires `checkout_start` with `source: solution-bottom`. The category route stays as a secondary "Talk to us" link (`/contact?interest=...`), keeping the tailored ask the hero comment defends. `CATEGORY_CTA_MAP` is renamed to `CATEGORY_CONTACT_MAP` and loses its `dev-env -> ACCOUNT_PATH` row (that category's contact interest becomes `dev-environments`); `ctaHref` is removed from the config interface because no page sets it. PROFESSIONAL is the plan because it is the entry self-serve tier with the trial; an operator who prefers BUSINESS changes one constant.
- **Pricing final CTA** links to the same trial intent; "Talk to Sales" stays.
- **Home bottom CTA** keeps its destination (the portal is the funnel) and changes the label to "Create free account". The install path is the hero's job on the home page.
- **Social proof: delete, not park.** The component, both commented restore recipes, every `socialProof` subtree in 13 locales, the completeness exemption and the baseline rows go in one commit. The 2026-07-19 comment kept the keys "for a future honest replacement"; the replacement below is a different shape (no quote, no author, no company), so nothing in the old keys is reusable.
- **Honest proof (phase 2).** A new optional `proof` section (`SPProof.astro`) renders up to three measured numbers, each with a `methodologyHref` that must resolve to an existing docs or blog route, and a one-line "how this was measured" label. No attributed quote, no customer name, no logo. Content comes only from figures already published with method (for example the 241 GB clone timing and the 46-second cluster fork in the blog). Pages with no measured figure get no section.
- **Dead success page** is deleted with its translations; `/checkout/success` becomes a 410 in `redirects.json` (the `/careers` precedent), and the fetch-handler test's self-redirect example moves to another self-map (`/changelog`).
- **Analytics host and segmentation.** The loader admits exactly `new URL(WK_SITE_ORIGIN).hostname`, through an `isAnalyticsHost` helper in `marketing-host.ts` that the inline copy mirrors (the file's existing sync rule). Each pageview carries a `section` custom property (`docs`, `blog`, `marketing`) from the path, so the conversion denominator can exclude docs and blog traffic.
- **Out of scope.** The Plausible dashboard's goal and segment definitions and the written conversion-rate metric are operator-side settings on plausible.rediacc.com (box O1 records them; no code changes them). Portal-side measurement is PLAN-portal-analytics.md.
