## Design

**Verify, then fix.** Clusters 1, 3, 4, 5, 7, 8, 10 and 11 are fixed on the branch and get verify-only boxes; each closes on its local command today and on N0's classification after the merge. No box re-fixes them.

**The recurrence class is the clock.** Five of the eleven nightly reds were caused by the calendar, not by a commit: hold expiry, release-age windows, 45-day baselines, plan age, an upstream rebuild. The drift job already runs the clock gates daily, but it reports them on the day they turn red. The durable fix is a forecast: a single clock seam, `REDIACC_GATE_CLOCK` (an ISO-8601 instant, read by `rediacc_ci.core.gate_clock.now()` in Python and by one helper in check-pin-freshness.ts), honoured by every clock gate in place of its direct `datetime.now` read. `drift_job` gains a forecast pass that re-runs `CLOCK_GATE_IDS` with the clock set 7 days ahead. A forecast red does not change the job's exit code; it is written to the verdict JSON as `forecast` and posted with it, so the Stop hook's ops-health block names the gate and the date a week before it reds main. `check:ci-runner-advice` and `check:ci-secret-reachability` join `CLOCK_GATE_IDS` (Context 3). The seam is honoured only as an override of `now`, never as a skip, and a test plants a clock past each gate's deadline and expects red.

**The OBS check stays red by design.** A moved upstream breaks `renet ceph install` on Leap for every customer until the pin ships (`.ci/rediacc_ci/infra/renet_pkg_matrix.py:415`), so the plan does not demote it. Main's lag is a merge-cadence fact, which the forecast cannot predict (OBS rebuilds without notice). A1 bumps the branch pin now so the first post-merge run starts current, and V6 proves the renamed autobump works from main after the merge.

**Out of scope.** The weekly/daily split itself, the stable promotion trigger and the ops-health alerting are PLAN-health-checks-local.md's. The CUDA base bump (Context 2a) needs a GPU narration host; A2 decides hold-or-bump and does not build the image.

## Risks

- The forecast pass doubles the clock gates' run time in the drift job; they are cheap (seconds each), but F2 records the measured wall time so the drift job's 30-minute timeout is not approached silently.
- A seam that overrides `now` can be misused as a skip. F1's tests plant a clock past each deadline and require red, so a gate that ignores the seam, or treats it as an excuse, fails its own test.
- OBS may rebuild again between A1 and the merge. V6 covers that path once the autobump runs from main; until the merge, a session re-runs A1's command.
- N0 may show reds no cluster predicted, because 3223 commits land at once. N0 turns each into a box rather than closing over it.
