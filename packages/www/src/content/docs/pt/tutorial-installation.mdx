# Instalação

Instalar o `rdc` são três passos: abra a página de instalação, escolha o seu sistema operativo e cole o comando no seu terminal. Normalmente demora um ou dois minutos no total.

## Os três passos

![Three steps overview](/img/tutorials/tutorial-installation/slide-1.svg)

1. Abra a [página de instalação](/pt/install).
2. Escolha o seu sistema operativo.
3. Copie o comando de instalação e cole-o no seu terminal.

## Passo 1: Instalar o CLI

<TutorialStep number={1} />

A página de instalação gera o comando certo para si. No Windows (PowerShell), o comando equivalente numa linha é:

```powershell
iwr -useb https://www.rediacc.com/install.ps1 | iex
```

> O prefixo `time` é um truque da shell que mostra quanto tempo um comando demorou. Usamo-lo ao longo desta série para que possa ver a velocidade real de cada passo. É opcional. Ignore-o se não quiser.

## Passo 2: Verificar a instalação

<TutorialStep number={2} />

Execute `rdc doctor` para verificar o Node, o SSH e as restantes dependências do `rdc` e reportar quaisquer lacunas.

## Porquê o `rdc` vive no seu computador portátil

![rdc on your laptop, renet on the server](/img/tutorials/tutorial-installation/slide-2.svg)

O `rdc` é o CLI no seu computador portátil. O servidor executa um componente separado chamado `renet`, que o `rdc` provisiona e controla via SSH. Nunca precisa de fazer SSH para um servidor manualmente. O `rdc` encarrega-se disso. Esse é o modelo: uma ferramenta na sua máquina, nada para gerir diretamente no servidor.

Vamos cobrir a configuração do renet nos próximos dois tutoriais. É mais envolvido do que a instalação do CLI, mas faz-se apenas uma vez por máquina.
