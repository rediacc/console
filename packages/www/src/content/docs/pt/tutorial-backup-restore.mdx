# Backup e Restauro

A sua aplicação está em produção. Crie uma cópia de segurança. O `rdc` copia um repositório inteiro, a aplicação, a sua base de dados, os seus ficheiros e a sua configuração, para uma segunda máquina, e recupera-o quando a primeira desaparecer.

Este tutorial não se limita a descrever isso. Fá-lo, em duas máquinas reais, e lê os dados de volta no final.

## Três passos

![Copiar, restaurar, provar](/img/tutorials/tutorial-backup-restore/slide-1.svg)

1. **Copie** o repositório para uma máquina que controla.
2. **Restaure** essa cópia para um repositório próprio.
3. **Prove** lendo os seus dados de volta.

## Passo 8: Backups pelos quais pode retroceder

<TutorialStep number={8} />

Na sua própria instalação, com uma conta, a sequência completa é:

```bash
rdc backup snapshot my-app
rdc backup manifests my-app
rdc backup restore my-app --as my-app-yesterday --at <snapshot-id> --up
```

O [guia de Backup e Restauro](/pt/docs/backup-restore) cobre snapshots, retenção e verificação em detalhe.
