# Sauvegarde et restauration

Votre application est en production, en direct. Sauvegardez-la. `rdc` copie un dépôt entier, l'application, sa base de données, ses fichiers et sa configuration, vers une seconde machine, et le ramène quand la première a disparu.

Ce tutoriel ne se contente pas de le décrire. Il le fait, sur deux machines réelles, et relit les données à la fin.

## Trois étapes

![Copier, restaurer, prouver](/img/tutorials/tutorial-backup-restore/slide-1.svg)

1. **Copiez** le dépôt vers une machine que vous contrôlez.
2. **Restaurez** cette copie dans un dépôt qui lui est propre.
3. **Prouvez**-le en relisant vos données.

## Étape 8 : Des sauvegardes que vous pouvez rembobiner

<TutorialStep number={8} />

Sur votre propre installation, avec un compte, la séquence complète est :

```bash
rdc backup snapshot my-app
rdc backup manifests my-app
rdc backup restore my-app --as my-app-yesterday --at <snapshot-id> --up
```

Le [guide Sauvegarde et restauration](/fr/docs/backup-restore) couvre les instantanés, la rétention et la vérification en détail.
