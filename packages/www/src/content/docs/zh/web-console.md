# 网页控制台

网页控制台是覆盖整个 `rdc` CLI 的浏览器界面。每个 CLI 命令在控制台中都对应一个表单，包含校验、资源选择器和运行按钮。这里不存在独立的"网页功能集"：控制台是从 CLI 合约自动生成的，因此 CLI 拥有的任何命令，控制台也都会有，新增命令也会自动出现。

它位于网页门户的 `/account/console`。

## 可用性

网页控制台是付费功能。它包含在付费方案中，在 Community 方案中会被隐藏。访问权限也受角色控制，因此组织管理员可以决定谁能看到它。

## 与配置存储的关系

控制台从您的加密配置存储中读取资源（机器、仓库等），并且只在浏览器中解密该配置。这意味着：

- **处于锁定状态时**，您仍然可以浏览完整的命令目录、打开任意命令的表单并查看其参数。这一切都无需任何设置即可完成。
- **要运行命令并使用选择器**，您需要先解锁配置存储（通行密钥、主密码或恢复码，参见[配置存储](/zh/docs/config-storage)）。运行按钮、资源页面和资源选择器都以已解锁的会话为前提。

解密后的密钥只保留在浏览器内存中。刷新页面会重新锁定控制台，30分钟无操作也会自动锁定。

## 资源选择器

解锁后，命令表单会用基于您解密后配置生成的选择器替换自由文本字段：机器、仓库、数据存储、存储、集群、云提供商和备份策略。部分选择器则通过实时运行命令来解析，例如某台机器上的容器，或数据存储中的快照。

选择器之间存在依赖关系：选定一台机器后，仓库选择器会自动缩小到该机器范围内。对于仓库引用，引用构建器会根据各项选择组合出完整的 `name:tag@machine` 形式。选择器只是提示，不是强制约束，您始终可以手动输入值。

## 运行命令

浏览器从不持有 SSH 密钥或机器地址。点击运行时，控制台只发送命令意图——即运行哪个命令、使用哪些参数——由执行器解析其余部分并执行。相关工作原理以及哪些命令可以这样运行，参见[代理与执行器](/zh/docs/proxy-and-executor)。

只修改配置的命令（例如创建一条机器记录）根本不会远程执行。控制台会将它们路由到内置的配置编辑器，修改内容会像其他配置修改一样被加密并推送。

每个表单还会显示对应的 CLI 命令行，因此您在控制台中设置的任何内容都可以直接复制到终端或脚本中。

## 控制台导览

- **资源页面**：机器、仓库和任务各自拥有列表页和详情页，相关命令作为操作附加在上面。
- **命令面板**：按 Cmd-K（Ctrl-K）可以按名称跳转到任意命令或资源。
- **运行历史**：过往的运行记录按会话保留，方便您查看输出并使用相同参数重新运行。
