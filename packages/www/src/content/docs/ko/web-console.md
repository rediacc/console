# 웹 콘솔

웹 콘솔은 전체 `rdc` CLI를 브라우저 UI로 감싼 것입니다. 모든 CLI 명령은 콘솔에서 폼, 유효성 검사, 리소스 선택기, 실행 버튼과 함께 나타납니다. 별도의 "웹 전용 기능 세트"는 없습니다. 콘솔은 CLI 계약으로부터 생성되므로, CLI에 있는 명령이라면 콘솔에도 있으며 새 명령도 자동으로 나타납니다.

웹 콘솔은 웹 포털의 `/account/console`에 있습니다.

## 이용 가능 여부

웹 콘솔은 유료 기능입니다. 유료 플랜에는 포함되어 있으며 커뮤니티 플랜에서는 숨겨집니다. 접근 권한은 역할별로도 제한되므로, 조직 관리자는 누가 볼 수 있는지 제어할 수 있습니다.

## 설정 저장소와의 관계

콘솔은 암호화된 설정 저장소에서 사용자의 리소스(머신, 레포지토리 등)를 읽어오며, 해당 설정은 브라우저에서만 복호화됩니다. 즉,

- **잠긴 상태에서도** 전체 명령 카탈로그를 둘러보고, 어떤 명령의 폼이든 열어 매개변수를 확인할 수 있습니다. 별도의 설정 없이 가능합니다.
- **명령을 실행하고 선택기를 사용하려면** 먼저 설정 저장소의 잠금을 해제해야 합니다(패스키, 마스터 비밀번호, 또는 복구 코드, [설정 저장소](/ko/docs/config-storage) 참조). 실행 버튼, 리소스 페이지, 리소스 선택기는 모두 잠금 해제된 세션이 있어야 동작합니다.

복호화된 키는 브라우저 메모리에만 유지됩니다. 페이지를 새로고침하면 콘솔은 다시 잠기며, 30분 동안 활동이 없어도 자동으로 잠깁니다.

## 리소스 선택기

잠금이 해제되면 명령 폼은 자유 입력 필드 대신 복호화된 설정에서 가져온 선택기로 대체됩니다. 머신, 레포지토리, 데이터스토어, 스토리지, 클러스터, 클라우드 제공자, 백업 전략 등입니다. 일부 선택기는 명령을 실행해 실시간으로 값을 가져옵니다. 예를 들어 머신의 컨테이너 목록이나 데이터스토어의 스냅샷 목록이 그렇습니다.

선택기는 서로 의존적으로 필터링됩니다. 머신을 선택하면 레포지토리 선택기가 해당 머신으로 좁혀집니다. 레포지토리 참조의 경우, 참조 빌더가 개별 선택 항목으로부터 `name:tag@machine` 전체 형식을 구성해줍니다. 선택기는 어디까지나 힌트일 뿐 제약이 아니므로, 언제든 값을 직접 입력할 수 있습니다.

## 명령 실행

브라우저는 SSH 키나 머신 주소를 전혀 보유하지 않습니다. 실행을 클릭하면 콘솔은 어떤 명령을 어떤 매개변수로 실행할지에 대한 의도만 전송하고, 실행기가 나머지를 모두 해석해 실행합니다. 이 방식이 작동하는 원리와 어떤 명령이 이렇게 실행될 수 있는지는 [프록시 & 실행기](/ko/docs/proxy-and-executor)를 참조하세요.

설정만 편집하는 명령(예: 머신 항목 생성)은 원격에서 전혀 실행되지 않습니다. 콘솔은 이런 명령을 내장 설정 편집기로 라우팅하며, 변경 사항은 다른 설정 편집과 마찬가지로 암호화되어 푸시됩니다.

각 폼은 동등한 CLI 명령줄도 함께 보여주므로, 콘솔에서 설정한 내용을 그대로 터미널이나 스크립트에 복사해 사용할 수 있습니다.

## 콘솔 둘러보기

- **리소스 페이지**: 머신, 레포지토리, 작업(job)은 각각 목록 페이지와 상세 페이지를 가지며, 관련 명령이 액션으로 연결되어 있습니다.
- **명령 팔레트**: Cmd-K(Ctrl-K)를 누르면 이름으로 어떤 명령이나 리소스로도 바로 이동할 수 있습니다.
- **실행 기록**: 과거 실행 내역은 세션별로 보관되어 출력을 다시 확인하거나 동일한 매개변수로 재실행할 수 있습니다.
