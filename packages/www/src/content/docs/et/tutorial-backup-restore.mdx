# Varukoopia ja taastamine

Sinu rakendus on tootmises elus. Varunda see. `rdc` kopeerib terve repositooriumi, rakenduse, selle andmebaasi, failid ja konfiguratsiooni, teise masinasse ja toob selle tagasi, kui esimene on kadunud.

See juhend ei piirdu kirjeldamisega. See teeb seda, kahel päris masinal, ja loeb lõpuks andmed tagasi.

## Kolm sammu

![Kopeeri, taasta, tõesta](/img/tutorials/tutorial-backup-restore/slide-1.svg)

1. **Kopeeri** repositoorium masinasse, mida sa kontrollid.
2. **Taasta** see koopia oma repositooriumina.
3. **Tõesta** seda, lugedes oma andmed tagasi.

See ongi juhend. Mitte aruanne, et varukoopia õnnestus, vaid see rida ise, teisest masinast tagasi loetuna.

## 8. samm: varukoopiad, mille kaudu saad tagasi kerida

<TutorialStep number={8} />

Sinu enda installatsioonis, kontoga, on täielik jada:

```bash
rdc backup snapshot my-app
rdc backup manifests my-app
rdc backup restore my-app --as my-app-yesterday --at <snapshot-id> --up
```

[Varundamise ja taastamise juhend](/et/docs/backup-restore) käsitleb hetktõmmiseid, säilitamist ja kinnitamist täies mahus.
