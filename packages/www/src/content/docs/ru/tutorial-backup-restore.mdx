# Резервное копирование и восстановление

Ваше приложение работает в продакшене. Создайте резервную копию. `rdc` копирует целый репозиторий, приложение, его базу данных, файлы и конфигурацию, на вторую машину и возвращает его обратно, когда первая машина исчезает.

Этот урок не просто рассказывает об этом. Он проделывает это на двух реальных машинах и в конце считывает данные обратно.

## Три шага

![Копировать, восстановить, доказать](/img/tutorials/tutorial-backup-restore/slide-1.svg)

1. **Скопируйте** репозиторий на машину, которую контролируете сами.
2. **Восстановите** эту копию в отдельный репозиторий.
3. **Докажите** это, считав свои данные обратно.

## Шаг 8: Резервные копии, через которые можно откатиться назад

<TutorialStep number={8} />

В вашей собственной установке, с учётной записью, полная последовательность выглядит так:

```bash
rdc backup snapshot my-app
rdc backup manifests my-app
rdc backup restore my-app --as my-app-yesterday --at <snapshot-id> --up
```

[Руководство по резервному копированию и восстановлению](/ru/docs/backup-restore) полностью описывает снапшоты, хранение и проверку.
