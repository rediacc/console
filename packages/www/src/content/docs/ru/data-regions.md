При создании аккаунта Rediacc вы выбираете регион данных. Все ваши данные остаются в этом регионе. Этот выбор постоянен и не может быть изменён после регистрации. Миграции между регионами не поддерживаются. Выбирайте регион на основе требований к месторасположению данных вашей организации, а не на основе того, где находятся ваши серверы сегодня.

## Доступные регионы

| Регион | Расположение | Домен |
|---|---|---|
| **Европа (EU)** | Европейский союз | `eu.rediacc.cloud` |
| **США (US)** | Восточная часть Северной Америки | `us.rediacc.cloud` |
| **Азиатско-Тихоокеанский регион** | Азиатско-Тихоокеанский регион | `asia.rediacc.cloud` |

В столбце расположения указан регион Cloudflare, а не город, где стоит дата-центр. Cloudflare не обещает никакого города.

Продукт работает на этих доменах `rediacc.cloud`. Вся документация и маркетинговый сайт находятся на `www.rediacc.com`, который направляет вас в нужный регион через выбор региона.

При регистрации выбор региона предлагает вариант по вашему местоположению, а вы подтверждаете его или меняете. При входе он перенаправляет вас в ваш регион после короткого обратного отсчёта, который можно отменить или изменить. Если у вашей компании своё развёртывание, пункт «Вы корпоративный клиент?» приведёт вас туда по рабочей почте. Для поиска региона передаётся только домен; почта лишь заранее подставляется на странице входа.

## Что остаётся в вашем регионе

Эти типы данных хранятся и обрабатываются в выбранном вами регионе, за исключением транзакционной почты для Азиатско-Тихоокеанского региона: она отправляется через endpoint ЕС (что именно гарантируется, см. в разделе об инфраструктуре ниже):

- **Данные аккаунта**: email, имя, организация, членство в командах
- **Записи о выставлении счетов и подписках**: план, активации, выдачи лицензий
- **Зашифрованные блобы конфигурации**: зашифрованы на стороне клиента с нулевым разглашением. Сервер не может их расшифровать.
- **Транзакционные email**: сброс пароля, магические ссылки, уведомления. Отправляются с регионального эндпоинта email.

## Что является глобальным

Следующее не привязано к конкретному региону:

- **Артефакты релизов CLI**: публичные бинарные файлы, размещённые на глобальной CDN
- **Маркетинговый сайт и документация**: `www.rediacc.com`, обслуживается глобально из граничных узлов
- **Обработка платежей Stripe**: выполняется собственной инфраструктурой Stripe в соответствии с их соглашением об обработке данных

## Региональная инфраструктура

| Компонент | EU | US | Asia |
|---|---|---|---|
| База данных (D1) | Подсказка: Восточная Европа (EEUR) | Подсказка: восток Северной Америки (ENAM) | Подсказка: Азиатско-Тихоокеанский регион (APAC) |
| Хранилище конфигурации (R2) | Юрисдикция EU (гарантия) | Без юрисдикции (наилучшие усилия) | Без юрисдикции (наилучшие усилия) |
| Email (SES) | Франкфурт (eu-central-1) | Вирджиния (us-east-1) | Франкфурт (eu-central-1) |

Гарантированной юрисдикцией ограничено только хранилище конфигурации в EU: Cloudflare удерживает объекты R2 под юрисдикцией EU в пределах EU. Размещение базы данных D1 и хранилища US и Азиатско-Тихоокеанского региона опираются на подсказки о расположении и действуют по принципу «наилучших усилий». Cloudflare не гарантирует, что они работают в указанном регионе.

Каждый регион работает на независимой инфраструктуре. Межрегиональных запросов и потоков данных между регионами нет.

## Гарантии для региона EU

Если на вас распространяются европейские требования к резидентности данных, регион EU даёт одну жёсткую гарантию и размещение по принципу «наилучших усилий»:

- **База данных D1**: размещается по подсказке расположения EEUR (Восточная Европа); это наилучшие усилия, а не гарантия
- **Хранилище конфигурации R2**: ограничено юрисдикцией EU, и Cloudflare это гарантирует (жёсткое ограничение, а не просто подсказка расположения)
- **Email**: отправляется из Франкфурта (eu-central-1)

Подробное сопоставление с GDPR см. в [Соответствие GDPR](/ru/docs/legal-gdpr).

## Шифрование с нулевым разглашением

Блобы конфигурации, хранимые в R2, шифруются на стороне клиента перед загрузкой с использованием обмена ключами X25519 и AES-256-GCM. Сервер хранит только зашифрованный текст. Ни Rediacc, ни какой-либо провайдер инфраструктуры не может прочитать ваши данные конфигурации.

Ключи формируются из ключа доступа с расширением PRF. Сервер хранит серверный секрет, участвующий в формировании ключа, но ни ключ доступа в одиночку, ни серверный секрет в одиночку не могут расшифровать данные.

Подробности об архитектуре шифрования см. в [Хранилище конфигурации](/ru/docs/config-storage).

## Как выбрать

- **Выберите регион, ближайший к вам** для минимальной задержки.
- **Выберите регион, требуемый вашей организацией** для соблюдения требований. Если ваша компания требует хранения данных в EU, выберите EU.
- **Выбор постоянен.** Вы не можете перенести аккаунт в другой регион после регистрации.

## Для специалистов по соответствию требованиям

Технические свойства региональной архитектуры:

- **Отдельные базы данных для каждого региона**: каждый регион имеет собственную базу данных Cloudflare D1. Межрегиональных запросов нет.
- **Отдельные хранилища для каждого региона**: каждый регион имеет собственный R2-бакет. Юрисдикцией ограничен только бакет EU; US и Азиатско-Тихоокеанский регион размещаются по принципу «наилучших усилий».
- **Доставка email через AWS SES**: транзакционные email отправляются через AWS SES. EU и US используют выделенные региональные эндпоинты; Азиатско-Тихоокеанский регион использует EU эндпоинт (eu-central-1).
- **Один пользователь - один регион**: аккаунт пользователя существует ровно в одном регионе. Он не может охватывать несколько регионов.
- **Изоляция вебхуков**: события вебхуков Stripe принимаются всеми региональными воркерами, но обрабатываются только регионом, владеющим записью клиента.
- **Шифрование конфигурации с нулевым разглашением**: сервер не может читать данные конфигурации. Ключи шифрования никогда не покидают клиентское устройство.

Более широкий обзор соблюдения требований к суверенитету данных см. в [Суверенитет данных](/ru/docs/legal-data-sovereignty).
