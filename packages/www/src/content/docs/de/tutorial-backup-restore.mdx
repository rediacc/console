# Backup und Wiederherstellung

Ihre App läuft im Produktivbetrieb. Sichern Sie sie ab. `rdc` kopiert ein gesamtes Repository, die App, ihre Datenbank, ihre Dateien und ihre Konfiguration, auf eine zweite Maschine und holt es zurück, wenn die erste verschwunden ist.

Dieses Tutorial beschreibt das nicht nur. Es tut es, auf zwei echten Maschinen, und liest die Daten am Ende wieder aus.

## Drei Schritte

![Kopieren, wiederherstellen, beweisen](/img/tutorials/tutorial-backup-restore/slide-1.svg)

1. **Kopieren** Sie das Repository auf eine Maschine, die Sie kontrollieren.
2. **Stellen** Sie diese Kopie als eigenständiges Repository wieder her.
3. **Beweisen** Sie es, indem Sie Ihre Daten wieder auslesen.

## Schritt 8: Backups, durch die Sie zurückrollen können

<TutorialStep number={8} />

Auf Ihrer eigenen Installation, mit einem Konto, lautet die vollständige Abfolge:

```bash
rdc backup snapshot my-app
rdc backup manifests my-app
rdc backup restore my-app --as my-app-yesterday --at <snapshot-id> --up
```

Der [Backup-&-Wiederherstellungs-Leitfaden](/de/docs/backup-restore) behandelt Snapshots, Aufbewahrung und Verifizierung vollständig.
