# インシデントレポート

宣言されたインシデント([インシデント対応](/ja/docs/incident-response))からは、お客様が規制当局に提出するための3つの段階別レポートが生成されます。Rediacc は証拠から文書を生成します。インシデントが重大か、報告義務があるかは、引き続きお客様の判断であり、すべてのレポートにその旨が記されます。

## 段階

各段階には、必要なセクションだけが含まれます。その段階で不要なセクションは、空欄で残されずに省かれます。

| 段階 | 期限 | 追加内容 |
|---|---|---|
| 早期警戒 | 認識の24時間後 | ヘッダー、タイムライン、侵害指標、悪意の疑いと国境を越える影響 |
| 通知 | 認識の72時間後 | 初期評価、データへの影響(カテゴリ、概数、加盟国)、ATT&CK の手法 |
| 最終 | 通知の暦月で1か月後 | 根本原因と緩和策 |

最終報告は通知のあとに続くため、先に通知を生成します。各段階には、前の段階のセクションが含まれます。

レポート内のすべての事実には、どう分かったかが示されます。証拠で観測されたもの、お客様が入力したもの、推定されたもののいずれかです。推定された事実には、確信度と検知器の理由が付きます。評価、データカテゴリ、加盟国、推定原因、実施した対応、連絡窓口、手法は、生成の前にお客様がインシデントページで入力する項目です。

## 形式

| 形式 | 用途 |
|---|---|
| JSON | 正規の、検証可能な形式 |
| STIX 2.1 | 脅威インテリジェンスツール向けの指標バンドル |
| PDF | 非ラテン文字も表示できる読みやすい文書で、免責事項、QR コード、レポートのハッシュが各ページのフッターに入ります |

インシデントページでは、各段階に形式ごとのダウンロードボタンがあります。コマンドラインからは次のとおりです。

```bash
rdc incident export <id> --stage early-warning
rdc incident export <id> --stage notification --format stix
rdc incident export <id> --stage final --format pdf --out ./reports
```

形式の既定は JSON です。`--format` は `--stage` と一緒に使う場合のみ有効です。ファイルはレポート ID の名前で書き出されます。

## 署名と検証

各レポートは Ed25519 のレポートキーで署名され、レポート ID、段階、ハッシュは公開記録に載ります。署名はレポートの正規の内容を対象とするため、署名後の変更はすべて検出されます。

レポートは3か所で確認できます。

- `/account/verify/report/<id>` の検証ページ。PDF 上の QR コードがここを開きます。確認はブラウザー内で、公開されたレポートキーに対して行われ、何もアップロードされません。JSON ファイルは完全に確認されます。PDF はブラウザーで再ハッシュできないため、ページは PDF がレポートのハッシュを持つことを確認し、完全な確認には JSON ファイルを案内します。
- コマンドライン。JSON レポートの場合:

```bash
rdc forensics verify --report ./reports/<report-id>.json
```

内容または署名が一致しない場合、コマンドは終了コード 1 で終わります。PDF は、元になった JSON レポートを通じて検証します。

- レポート内の証拠スタンプ。ウィンドウに対する Verify evidence の結果として、誰が、どのバージョンで、いつ検証したかが記録されます。

## 項目の対応表

レポートの各項目は、お客様が報告する規制の枠組みに対応付けられているため、内容を打ち直さずに転用できます。対応表がカバーするのは3つの枠組みです。NIS2 第23条第4項、実施規則(EU)2025/302 のインシデント通知様式、GDPR 第33条第3項です。例:

| レポートの項目 | NIS2 | GDPR |
|---|---|---|
| 認識の時刻 | 第23条(4)(a) | 第33条(1) |
| 時系列 | 第23条(4)(d) | 第33条(3)(a) |
| 連絡窓口 | 第23条(4) | 第33条(3)(b) |

ある枠組みに対応する項目がない場合は、省かずに理由が記されます。たとえば、GDPR 第33条第3項の通知には、参照番号や終了時刻がありません。

## レポートが主張しないこと

すべての段階に、2つの記述が印字されます。

- フロー記録が証明するのは量と宛先であり、内容ではありません。
- インシデントが重大か、報告義務があるかは、お客様の判断です。

Rediacc は、お客様に代わって規制当局に何かを提出することはありません。
